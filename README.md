# DeskRecipeManager

デスク写真に「デスクレシピ」（使っている機材の名前ラベルと引き出し線）を付けて、画像として書き出せるWebアプリです。

**▶ アプリを開く: https://razilyis.github.io/DeskRecipeManager/**

インストール不要で、PC・スマホのブラウザからそのまま使えます。
処理はすべてブラウザの中で行われ、写真がサーバーにアップロードされることはありません。

## できること

- 写真の機材をタップして名前を入れるだけで、角丸ラベルと引き出し線を自動で配置
- ラベル・点をドラッグで調整、1つのラベルから複数の場所へ線を引く
- 線は「曲線」か「直線（1回折れ曲がる線）」から選択
- 文字サイズ、ラベルの色・不透明度、文字色、線の色・太さ、点の大きさを調整
- 表示の拡大・縮小（ピンチ／マウスホイール）と、画像の90°回転
- 元の写真と同じ解像度でPNG書き出し
- 作業途中をプロジェクトファイル（JSON）として保存・再開

## 使い方

1. 「画像を開く」でデスクの写真を選ぶ（PCではドラッグ＆ドロップや Ctrl+V での貼り付けも可）
2. 写真の中の機材をタップ／クリックして、機材名を入力
   - ラベルが自動で配置され、その場所まで線でつながります
   - Shift+Enter（スマホは改行キー）で2行のラベルにできます
3. ラベルや点（ポイント）をドラッグして位置を調整
   - ラベルをダブルクリック／ダブルタップすると文字を編集できます
   - 「線を追加」を押してから写真をタップすると、同じラベルから別の場所へ線を引けます
4. 「PNGで書き出し」で画像を保存

### 操作のヒント

| 操作 | PC | スマホ |
| --- | --- | --- |
| ラベルを追加 | 写真をクリック | 写真をタップ |
| 拡大・縮小 | マウスホイール／右下の −・＋ | ピンチ／右下の −・＋ |
| 表示を移動（拡大中） | 何もない所をドラッグ | 何もない所をドラッグ |
| 全体表示に戻す | 右下の ％ ボタン | 右下の ％ ボタン |
| 画像を回転 | 右下の ⟲・⟳ | 右下の ⟲・⟳ |
| 元に戻す | Ctrl+Z／「元に戻す」 | 「元に戻す」 |
| ラベルを削除 | Delete キー／「削除」 | 「削除」 |
| ラベルの微調整 | 矢印キー（Shift で10px） | ― |

PCでは「パネルを隠す」「全画面」で作業スペースをさらに広くできます。

## 開発

ビルド不要の HTML / CSS / JavaScript だけで作られています。

```
index.html      画面の構成
css/style.css   見た目（PC・スマホのレイアウト）
js/app.js       描画と操作のすべて
.github/workflows/pages.yml  GitHub Pages への自動デプロイ
```

ローカルで動かすときは `index.html` をブラウザで開くか、簡易サーバーを立ててください。

```sh
python3 -m http.server 8000
# http://localhost:8000 を開く
```
