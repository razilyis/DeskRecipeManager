# DeskRecipeManager

デスク写真に「デスクレシピ」（使っている機材の名前ラベルと引き出し線）を付けて、画像として書き出せるWebアプリです。
ブラウザだけで動き、画像はどこにもアップロードされません。

## 使い方

1. 「画像を開く」でデスクの写真を選ぶ（ドラッグ＆ドロップ、Ctrl+V での貼り付けも可）
2. 写真の中の機材をタップ／クリックして、機材名を入力
   - ラベルが自動で配置され、ポイントまで曲線の引き出し線でつながります
   - Shift+Enter（スマホは改行キー）で2行のラベルにできます
3. ラベルや点（ポイント）はドラッグで位置を調整
   - ラベルをダブルクリック／ダブルタップすると文字を編集
   - 「線を追加」で1つのラベルから複数の場所へ線を引けます
4. 「PNGで書き出し」で元画像と同じ解像度の画像を保存

文字サイズ・ラベルの色や不透明度・線の色や太さ・曲線／直線などは「スタイル」で変更できます。
「プロジェクト保存」で画像とラベルをまとめたJSONを保存し、「プロジェクトを開く」で続きから編集できます。

### 画面

- PC：画像が作業領域いっぱいに表示されます。「パネルを隠す」「全画面」でさらに広く使えます
- スマホ：画像が画面幅いっぱいに表示され、文字入力は画面下部に出ます

## GitHub Pages で公開する

`main` に push すると `.github/workflows/pages.yml` で GitHub Pages に自動デプロイされます。
初回のみリポジトリの **Settings → Pages → Build and deployment → Source** を **GitHub Actions** に設定してください。

公開URL: `https://<ユーザー名>.github.io/DeskRecipeManager/`

## ローカルで動かす

ビルド不要です。`index.html` をブラウザで開くか、次のように簡易サーバーを立ててください。

```sh
python3 -m http.server 8000
# http://localhost:8000 を開く
```
